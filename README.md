# سَكينة وتلاوة — Sakinah & Tilawah

منصّة إسلامية شاملة + صدقة جارية، تعمل بالكامل على جهة العميل (Frontend) لخدمة المسلمين في كل مكان.

> ✦ هذا الموقع صدقةٌ جاريةٌ عن محمد هاني منير عكاشة (محمد عكاشة) ووالديه، ولكلّ من ساهم فيه أو نشره. ✦

✨ **المميزات**
- 👑 **تصميم عالمي فاخر** — واجهة بروح Apple-grade: زجاج مصنفر (Glassmorphism)، لمسات ذهبية، خلفيات هندسية إسلامية ناعمة، وتأثيرات تفاعلية سلسة. وضعان ليلي/نهاري فاخران.
- 🕌 **شعار ملكي** — أيقونة هندسية إسلامية (نجمة ثمانية + هلال + مصحف مذهّب) بتدرجات ذهبية، موضوعة في منتصف الهيدر.
- 🕌 **القرآن الكريم** — فهرس كامل لـ 114 سورة بخطٍّ عثمانيٍّ نقيّ، بحث فوري، نَسخ ومشاركة للآيات.
- 🎧 **التلاوة الصوتية والمرتلة** — مشغّل صوتٍ ذكي بتصميمٍ فاخر مع 18 قارئاً (أحمد العجمي، العفاسي، عبد الباسط، الحصري، المعيقلي...) وروابط MP3Quran موثوقة، أزرار تحكم كاملة، وتستمر التلاوة في الخلفية أثناء التنقّل بين الأقسام.
- 📻 **إذاعة القرآن الكريم المباشرة** — بثّ مباشر مستقر لإذاعة القاهرة والسعودية على مدار الساعة، يستمر في الخلفية.
- 🕌 **مواقيت الصلاة واتجاه القبلة** — مواقيت تلقائية حسب موقعك (Geolocation) مع عدّادٍ تنازليّ دقيق للصلاة القادمة وبوصلة قبلة.
- 📖 **الأربعون النووية** — 40 حديثاً صحيحاً مع شرحٍ مبسّطٍ مختصر وزرّ مشاركة.
- 📿 **توسيع حصن المسلم** — أذكار النوم، الوضوء، السفر، الاستخارة، الهم والحزن + محرك بحثٍ سريع.
- 📚 **التفسير الميسّر** — زرّ بجانب كل آية يعرض التفسير الميسّر دون مغادرة الصفحة.
- 📿 **الأذكار وحصن المسلم** — أذكار الصباح والمساء بعدّادٍ تفاعليّ محفوظ في الجهاز (LocalStorage).
- 🤲 **الرقية الشرعية والأدعية النبوية** — بخطٍّ كبيرٍ مريحٍ وواضح.
- 🔴 **السبحة الإلكترونية** — سُبحة ذكيّة بأهدافٍ وعدّادٍ محفوظ.
- 🌓 **وضعان**: الوضع الليلي الفاخر والوضع النهاري المريح، مع تبديل سلس محفوظ تلقائياً.
- 🌐 **ثلاث لغات**: العربية (RTL) · English (LTR) · Türkçe (LTR) مع تبديل فوري.
- 💛 **عن الموقع**: نبذة أدبية روحانية تبيّن صدقةً جارية عن المؤسّس ووالديه ولكلّ من ساهم.
- 📱 **متجاوبة بالكامل** وبتصميمٍ داكنٍ روحانيّ راقٍ بلمساتٍ ذهبية.

## 🚀 الرفع إلى Vercel
1. ارفع مجلّد المشروع إلى GitHub (أو استخدم `vercel` CLI).
2. اربط المستودع في [vercel.com](https://vercel.com) → سيتعرف تلقائياً على الموقع الثابت.
3. أو محليًا: `npx vercel --prod`.

## 🚀 الرفع إلى GitHub Pages
1. ارفع المشروع لمستودع GitHub.
2. **Settings → Pages** → اختر الفرع `main` والمجلد `/ (root)`.
3. فعّل الحفظ، وسيتولّد رابط الموقع.

## 🔍 تحسين محركات البحث (SEO)
- وسوم Meta متكاملة: Title جذاب بالكلمات المفتاحية، Description، Keywords، **Open Graph**، **Twitter Card**، وأيضاً **Canonical** + **hreflang** (عربي/إنجليزي/تركي).
- **JSON-LD Structured Data**: WebSite، WebApplication، وFAQPage — يظهر في نتائج غنية.
- **HTML دلالي**: `<h1>` واحد (الهوية)، `<h2>` لكل قسم، `<article>` للآيات والأحاديث، `<nav>`/`<header>`/`<main>` سليمة.
- **عناوين ديناميكية لكل قسم** تتحدّث عند التنقّل (SEO لصفحات متعددة).
- `robots.txt` + `sitemap.xml` جاهزان.
- أداء: خطوط `display=swap`، `preconnect` للمصادر، `prefers-reduced-motion`، وخفّة بلا مكتبات ثقيلة.

## 🗂 البنية
- الموقع موحّد في ملف واحد `index.html` (نقطة الدخول الوحيدة).
- يستخدم واجهات عامة مجانية (AlQuran Cloud API) لجلب النص القرآني، **بدون أي خادم أو قاعدة بيانات**.
- كل الإعدادات تُحفظ في متصفّح المستخدم (LocalStorage).
